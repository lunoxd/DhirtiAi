1. TECHNOLOGIES WE USE (DEAD SIMPLE)
------------------------------------------------------------------------
• Frontend (UI):       Next.js 16 (React, Turbopack)
• Styling:             Vanilla CSS (Discord Dark Theme #313338)
• Icons:               Lucide React Icons
• Backend API:         Node.js + Express.js
• Database:            SQLite database (managed via Prisma ORM)
• AI Engine:           Groq API (Active model: qwen/qwen3.6-27b) + Empathetic AI Engine
• Security & Auth:     JWT (JSON Web Tokens) + Bcrypt Password Hashing
